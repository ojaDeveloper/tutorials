最原始层 · 一切的地基

第 0 层：数与运算的本质

把"数"和"四则运算"抠到最底——上面每一层都踩在这
数
= 数量的标签。5 个苹果和 5 根手指"一样多"靠配对，数字只是贴上去的名字。
加法
= 合并。最原始的运算，其余全由它长出来。
减法
= 加法的逆（"还差多少"）。引出 负数 = 反方向（欠债、零下）。
乘法
= 重复加。3×4 就是 4+4+4。依赖：加法
除法
= 乘法的逆 / 平均分。引出 分数 = 把 1 切开。依赖：乘法
比例
= 除法的一种用法（"谁是谁的几倍"）。概率、期望、学习率全是比例。依赖：除法
本层顿悟：每个运算都在回答一个"逆问题"，而且 乘法只是加法的偷懒、除法只是乘法的偷懒。往上全部术语，最终都由加法长出来。
第一次抽象 · 操纵"还不知道的数"

第 1 层：代数与函数

AI 的一切都是"未知的旋钮"——先学会用字母思考
变量 x
= 装任意数的盒子。从 3+□=7 升级到 3+x=7，第一次操纵"未知"。
函数 f(x)
= 输入→输出的机器：给一个数，还你一个数。★ 整个 AI 模型就是一个巨大的 f，全教程的核心比喻。依赖：变量
y = w·x + b
一条直线：w 控多陡、b 控上下移。★ 这就是"一个神经元"的骨架，记死。依赖：乘法、加法
指数
= 重复乘。2³=2×2×2，翻倍再翻倍。依赖：乘法
对数 log
= 指数的逆，问"翻了几次"。log₂8=3。★ 损失函数里的 log 就是"数量级/翻倍次数"。依赖：指数
本层顿悟：万物皆可写成 f(x)；最简单的 f 就是直线 w·x+b——AI 的几十亿参数，本质就是无数个 w 和 b。
AI 的骨架 · 一个操作撑起半个 AI

第 2 层：线性代数（向量 · 点积 · 矩阵乘）

AI 的数据不是一个数，而是"一串数"和"一表数"
向量
= 一串数 [1.2,-0.3,0.8]。可看成"一个词的编码"，也可看成"空间里的箭头"。依赖：数
点积
= 对应相乘再相加，得一个数：[a,b]·[c,d]=ac+bd。方向越一致，点积越大 → 它就是"相似度打分"。★ 注意力的核心。依赖：乘法、加法
矩阵
= 一表数 / 一批向量，也可看成"对空间的一个变换"（旋转/拉伸/投影）。依赖：向量
矩阵 × 向量
= 一次做很多个点积。★ 神经网络"一层"的计算，就是一次矩阵乘。依赖：点积
shape 形状
= 行数×列数。AI 报错一大半是 shape 对不上，所以要会数。
本层顿悟：神经网络的每一层 = 一次矩阵乘法；而点积同时又是"相似度"。这一个操作，撑起半个 AI。
学习的引擎 · 回答"旋钮往哪拧"

第 3 层：微积分（导数 · 链式法则 · 梯度）

训练 = "往哪个方向调旋钮能让误差变小"，回答"方向"的数学就是导数
斜率
= Δy / Δx："x 动一点，y 动多少"——就是除法的一个用法。依赖：除法
导数
= 瞬时斜率：把 Δx 缩到无穷小。它告诉你旋钮往哪拧能让误差降。依赖：斜率
链式法则
= 一环套一环求导：dy/dx = dy/du × du/dx。★★ 这一条就是反向传播的全部数学：误差从最后一层，一环环乘回第一层。依赖：导数
偏导数
= 多个旋钮时，固定其它、只动一个的导数。几十亿旋钮就有几十亿偏导。依赖：导数
梯度
= 所有偏导打包成的向量，指向"误差上升最快"的方向；反过来走就是下降最快。依赖：偏导、向量
本层顿悟：反向传播不神秘，就是链式法则批量算梯度；训练每一步 = "算出梯度 → 往反方向挪一小步"。
不确定性的语言 · 模型不给答案，给概率

第 4 层：概率与统计（分布 · 期望 · softmax）

AI 输出的不是"确定答案"，而是"每个选项的概率"
概率
= 可能性的度量（0 到 1）= "占比"。依赖：比例
期望
= 加权平均：每个结果 × 它的概率，再相加。★ 损失就是误差的期望。依赖：乘法、加法
条件概率 P(A|B)
= 给定 B 后 A 的概率。★ 语言模型的本质就是 P(下一个词 | 前面的词)。
softmax
= 把一串分数变成一串概率：先各取指数（拉开差距、变正数），再除以总和（凑成 1）。★ 模型输出层就是它。依赖：指数、除法
极大似然
= 调旋钮，让"真实数据出现"的概率最大——这就是训练目标的本质。依赖：条件概率
本层顿悟：模型不输出答案，输出概率分布（softmax）；训练目标 = 让真实答案的概率尽量大。
损失函数从哪来 · 把"对不对"变成一个数

第 5 层：信息论（信息量 · 熵 · 交叉熵）

怎么把"猜得对不对"变成一个可求导的数？答案在这，直接产出 AI 的损失函数
信息量
= -log(概率)：越不可能的事，一旦发生信息量越大。用 log 是为了把"翻倍的稀有度"变成"加法的信息"。依赖：对数、概率
熵
= 平均信息量 = 不确定性：把信息量按概率加权平均。越乱越大。依赖：信息量、期望
交叉熵
= 用"模型以为的分布"去编码"真实分布"的代价。★★ 这就是损失函数：真答案是"苹果"，模型给苹果的概率越低，-log(概率) 越大，罚得越狠。依赖：熵
KL 散度
= 两个分布的"距离"。衡量"模型分布"离"真实分布"多远。依赖：交叉熵
本层顿悟：交叉熵损失 = -log(模型给正确答案的概率)——只盯正确答案那一项，概率越低惩罚越狠。
纠个常见错：你那份 Transformer 文档把交叉熵说成"两个分布做减法"，其实是取 -log（不是减法）；而且它反传时会把正确词往上推、所有错词往下压，不是"只惩罚某一个词"。
怎么调到最好 · 训练的心脏

第 6 层：优化（梯度下降 · SGD · 动量 · Adam）

有了"损失"(第5层)和"梯度"(第3层)，这层讲怎么一步步把损失调到最小
梯度下降
= 沿梯度反方向走一小步：新旋钮 = 旧旋钮 − 学习率 × 梯度。★ 这一行就是训练的心脏。依赖：梯度
学习率
= 每步迈多大。太大跨过最低点甚至飞出去，太小走到天荒地老。它是"比例"，在优化器里、不在模型里。依赖：比例
SGD
= 随机梯度下降：抽一小批数据估计梯度，快且带噪声（噪声还能帮忙逃出小坑）。依赖：梯度下降、期望
动量
= 给下山加惯性：把过去几步方向做加权平均，冲过小坑、加速直道。依赖：移动平均
Adam
= 每个旋钮有自己的步长：一阶矩(方向惯性) + 二阶矩(最近抖得凶就自动减速)。依赖：动量、方差
动画 · 梯度下降"下山"（拖学习率滑块，看它是稳稳到谷底、还是飞出去）
小球在"损失山谷"里。每走一步 = x ← x − 学习率 × 斜率。试试把学习率拉到 0.9 以上，看它怎么"跨过谷底反复横跳甚至飞走"。
纠个常见错：Adam 的二阶矩是"梯度平方的移动平均"（谁最近抖得凶就给谁减速），不是你文档里说的"历史加速度"，Adam 也和物理"动量定理"无关（它叫自适应矩估计）。
本层顿悟：训练 = 反复执行「算损失 → 反向传播求梯度 → 旋钮 −= 学习率×梯度」；Adam 只是让这一步更聪明。
合流① · 全是旧零件，没有新数学

第 7 层：看懂一个神经网络

把前 6 层拼起来——你会发现"训练神经网络"没有一个新数学
一个神经元
= 激活(w·x + b)：直线(第1层) + 一个掰弯。依赖：wx+b
激活函数
= 给直线掰个弯。没有它，多少层叠起来还是一条直线，学不了复杂东西。
前向传播
= 一连串矩阵乘 + 激活，最后 softmax 出概率。依赖：矩阵乘、softmax
反向传播
= 链式法则从输出层求梯度回到输入层。依赖：链式法则
参数更新
= 梯度下降 / Adam，每个 w、b 减去学习率×自己的梯度。依赖：梯度下降
本层顿悟：训练神经网络 = 前向(矩阵乘) → 损失(交叉熵) → 反向(链式法则) → 更新(梯度下降)，循环。全是第 0–6 层的零件。
合流② · 终点：通关那份 Transformer 文档

第 8 层：看懂 Transformer

把文档里每个数学符号，用前面学的东西逐一拆开
词向量
= 把"字"变成一串数，语义近的向量也近。依赖：向量
Q、K、V
= 对词向量各乘一个矩阵得到的三份新向量（查询/被查/内容）。依赖：矩阵乘
注意力打分
= Q·K 点积：两个词相关不相关，用点积量相似度。依赖：点积
÷ √dₖ
= 缩放，防点积太大 → softmax 饱和 → 梯度变小学不动（是防梯度消失；文档里一处说成"防爆炸"是反的）。
softmax(打分)
= 把相关度变成注意力权重（加起来=1）。依赖：softmax
加权求和 V
= 按注意力权重把各词内容混合（权重×向量再相加）。依赖：数乘、向量加法
多头
= 同时开好几套 Q/K/V 看不同角度，再拼起来。
词向量 → (注意力 ＋ 前馈 ＋ 残差 ＋ 归一化) × N 层 → softmax 出下一个词概率 → 交叉熵损失 → 反向传播 → Adam 更新
通关顿悟：Transformer = 一堆矩阵乘 + 点积 + softmax 叠 N 层，训练照样是"前向→交叉熵→反向→Adam"。文档里那句"一百多行代码"的每一行，现在都对应到你学过的某个数学零件。

验证你真的通关了

  • 拿注意力公式 softmax(QKᵀ/√dₖ)V，逐符号标注"这是第几层学的什么"。
  • 说清 -log(0.05) 为什么比 -log(0.8) 大 —— 对上"交叉熵为什么概率越低罚越狠"。
  • 用"链式法则"一句话解释"误差怎么从最后一层传回第一层"。
