公元前 · 绳子与土地

第 1 章：绝境——怎么在地上造出一个准确的直角？

勾股定理不是从公式来的，是从"盖房子要垂直"这个活命需求来的

先忘掉一切公式。公元前的埃及人、中国人面对一个真实的活儿：分田、盖屋、修金字塔，都需要标准的直角。可地上没有量角器，怎么保证两条边"正好垂直"？

他们发现的土办法：拿一根绳子，打上等距的结，量出 3 段、4 段、5 段 三条边，围成一个三角形——那个对着最长边（5）的角，必然是标准直角。这就是"结绳成直角"，埃及拉绳人靠它盖金字塔。

反复用下来，人们发现这不是巧合：只要三角形有一个直角，三条边（两条直角边 a、b 和斜边 c）之间就锁死了一个关系。古中国《周髀算经》把它记成"勾三股四弦五"。注意——此刻它还不是公式 a²+b²=c²，只是一句话、一张图、一组能用的数。

你问过："勾股定理的公式怎么出现的？从没有公式变成公式这一步我很不懂。" —— 答：那一步跨了两千年。公元前它是"图形+口诀"；直到 16–17 世纪欧洲发明了代数符号（用字母代表数、用 ² 记平方），人们才把这张老图翻译成 a²+b²=c²。公式是后来的"翻译稿"，不是原件。你觉得"突然变成公式"，是因为课本把这两千年的翻译过程删了。
这一步是"发现"
勾股关系是宇宙（平直空间）逼出来的，不是谁规定的——你把直角画歪一点，关系就不成立。人类只是发现了它。（能不能改成别的？在弯曲空间里它真的会变——这是后话，但足见它是"发现"不是"约定"。）
挖到基岩 · 你最较真的一问

第 2 章：★"平方"到底是怎么来的？怎么就刚好用平方？

你问："勾股定理是不是依赖面积？正方形面积自然叫平方？平方怎么来的？不然怎么刚好用平方"——这一章专门回答

你的直觉完全正确。a² 里那个"²"不是凭空的符号，它的本义就是——以 a 为边长的正方形，它的面积。

  • 先挖"平方 = 面积"：一个边长 a 的正方形，切成 a 行 a 列的小方格，一共 a×a 个。所以"a 乘 a"最原始的含义就是"边长 a 的正方形装了多少个单位方格" = 面积。先有正方形面积，才有"平方"这个词。
  • 再看勾股定理的真身：在直角三角形三条边上各向外画一个正方形。勾股定理说的其实是一句面积的话：两条直角边上的正方形面积之和（a² + b²）= 斜边上的正方形面积（c²）。
  • 所以"刚好用平方"一点不刚好：因为它本来就是正方形面积之间的关系，写出来自然是平方。如果当年人们比的是别的东西，就不会是平方。平方是"面积"逼出来的，不是硬凑的。
    • 交互图 · 亲眼看到 a² + b² 拼成 c²（拖滑块换三角形，看两种拼法剩下的面积必相等）
    看懂这张图，你就看懂了"图形证明"：左右两个一样大的大正方形（边长都是 a+b），里面都塞了4 个完全相同的直角三角形。把这 4 个三角形拿走，剩下的面积必然相等——左边剩的是中间那个斜正方形 c²，右边剩的是 a² 和 b² 两块。所以 c² = a² + b²。全程没写一个代数公式，纯靠"面积不会凭空多也不会凭空少"。
    正方形面积为什么是"边长×边长"？再往下挖一层
    因为我们约定了"面积"用"单位小方格的个数"来量（这是约定/定义，不是发现）。边长 a 的正方形，横着能放 a 个、竖着能放 a 行，所以是 a×a 个方格。再往下，"a×a"里的乘法，又能挖到第 1 层的"重复加法"（a×a = a 个 a 相加）。一直挖到底，是"数数"和"面积怎么定义"这两块基岩。
    你问过："勾股定理是不是已经是最底层的公式了，没有更底层的推导它了，只能联系图形？" —— 答：接近对，但更准确地说：它不能靠"更底层的公式"推，只能靠图形（面积）加几何公理来立。它是"接近地基"的一块砖，下面垫着的是"面积的定义"和"欧几里得几何公理"，不是别的公式。
    元层 · 你追问的"证明合法性"

    第 3 章：图形能算"严谨证明"吗？万一是特例呢？

    你问："由图得出公式，在数学上是能接受的严谨证明吗？万一是特例呢？谁认可这种证明方式？"

    这是全篇最"数学哲学"的一问，也是你反复戳的点。分三层回答：

  • 图形证明是合法的——只要它没偷用"特殊数值"。上一章那张拼图，我全程用的是字母 a、b（任意直角边），没说"a 必须等于 3"。所以它对一切直角三角形都成立，不是特例。"万一是特例"的担心，只在你用了具体数字（如 3、4、5）去"验证"时才成立；用字母做一般性论证，就堵死了特例。
  • 但图形也确实会骗人——历史上有很多"看图想当然"翻车的例子（比如画歪一点就得出荒谬结论）。所以从欧几里得开始，数学界约定了一套规矩：图只能用来"提示思路"，真正算数的是"每一步依据哪条公理/已证结论"。
  • "谁认可这种证明方式"？——是一套两千年沉淀下来的社区约定。不是某个人拍板，而是欧几里得《几何原本》立了范式（公理→定理→证明），后世数学家共同沿用、不断加严。所以"证明"本质是一种"约定的游戏规则"：从大家都接受的公理出发、每步合规、不自相矛盾，就被承认。你直觉到的"是不是定了个标准/格式"——完全正确。
    • "证明"这件事本身，是"约定"
    什么算证明、什么图能用、什么符号能创造——这些是数学共同体的约定（可以演化，比如后来加了代数证明、形式化证明）。但被证明的结论（如勾股定理）一旦立住，就是发现的真理。规则是约定的，规则下推出的真理是发现的。这句你记住，后面全通。
    你后来自己悟出一句很漂亮的话："从图形翻译成代数才需要证明，从代数换回图形不需要。" —— 这个直觉方向很对，第 6、8 章我们会把它精修成准确版本。你已经在用数学家的方式思考了。
    1637 · 笛卡尔 · 隔了两千年

    第 4 章：笛卡尔的约定——用两个数锁定一个点

    圆的方程为什么公元前写不出来？因为还差一个发明：坐标系

    勾股定理有了，但它是"图形里的关系"。要写出"圆的方程"，还缺一样东西——把"图上的点"变成"一对数"的办法。这一步 1637 年才由笛卡尔迈出。

  • 绝境：几何（图）和代数（数、方程）长期是两个互不相通的世界。图形不好算，代数看不见。笛卡尔想把它俩焊在一起。
  • 他的约定：在平面上画两条互相垂直的数轴（x 轴、y 轴），交点叫原点。这样平面上每一个点，都对应唯一一对数 (x, y)——x 是它离 y 轴多远，y 是它离 x 轴多远。
  • 威力：从此"图形"能翻译成"方程"，"方程"能画成"图形"。这就是解析几何的诞生。
    • 坐标系是纯粹的"约定/发明"
    它不需要证明——你没法"证明"该用垂直的两条轴，这是笛卡尔规定的游戏场地（换成斜的轴、极坐标也行，只是没这么方便）。这正好回答你问的"笛卡尔坐标系有定义规定才出现了圆"——对，圆的方程站在这个约定的地基上。
    1637 · 距离公式

    第 5 章：两点间距离为什么要"开根号"？（你说这里很莫名其妙）

    你问："这里又怎么涉及到开根号？也是莫名其妙。"——它一点不莫名，就是勾股定理

    有了坐标，第一个要算的就是：平面上两点 A(x₁,y₁) 和 B(x₂,y₂)，它俩离多远？

  • 造一个直角三角形：从 A 横着走到 B 的正下/正上方，横向走了 Δx = x₂−x₁；再竖着走到 B，竖向走了 Δy = y₂−y₁。这两段正好垂直（一横一竖），而 A 到 B 的直线距离，就是这个直角三角形的斜边。
  • 套勾股定理：斜边² = 横边² + 竖边²，即 距离² = Δx² + Δy²。
  • 要"距离"本身，就得把"距离²"还原回去——开根号：
    • 距离 = √( (x₂−x₁)² + (y₂−y₁)² )　←它整个就是勾股定理 c=√(a²+b²) 穿了坐标的衣服
    所以"开根号"一点不莫名：勾股定理给你的是"距离的平方"（因为它本质是面积关系），而你要的是"距离"本身。开根号 = 从"正方形面积"退回"正方形边长"的那一步逆操作。平方是"边长→面积"，开根号就是"面积→边长"，一来一回而已。
    开根号（√）这个运算是怎么来的？
    它就是"平方的逆问题"：已知一个正方形的面积，反求它的边长。就像减法是加法的逆、除法是乘法的逆，开根号是平方的逆。√ 这个符号是 16 世纪才发明的记号（又是"约定"），但"已知面积求边长"这个需求，古人早就有了。
    ★ 高潮 · 圆的方程诞生

    第 6 章：圆的方程，其实和勾股定理一模一样

    你惊呼过："圆的公式和勾股定理一模一样？？？"——是的，下面一步步给你逼出来

    圆是什么？先说定义（这是圆的"物理定义"，公元前就有）：到某个定点（圆心）距离都相等（等于半径 r）的所有点，连起来就是圆。

    现在把这句话，用第 4、5 章的工具翻译成方程。为简单起见，先把圆心放在原点 (0,0)：

  • 设圆上任意一点是 (x, y)。"它在圆上" 这句话，翻译过来就是："它到圆心 (0,0) 的距离 = r"。
  • 用第 5 章的距离公式：它到原点的距离 = √(x² + y²)。于是"在圆上"就是：√(x² + y²) = r。
  • 两边平方，把根号去掉（因为带根号难算，平方更清爽）：得到 x² + y² = r²。圆的方程，出生了。
    • x² + y² = r²　←把 x 看成 a、y 看成 b、r 看成 c，它就是 a²+b²=c²
    回答你的惊呼：对，一模一样！ x²+y²=r² 就是勾股定理 a²+b²=c²。因为圆上每个点 (x,y) 到圆心，正好张出一个直角三角形（横边 x、竖边 y、斜边 r=半径），而"半径永远是 r"（圆的定义）就锁死了 x²+y²=r²。圆的方程 = 勾股定理 + "所有点半径都相等"这一句定义。一点都不莫名其妙。
    交互图 · 拖动圆上的点，看那个"勾股直角三角形"始终满足 x²+y²=r²
    这是"翻译 + 推导"，不是"先写后补证明"
    你问过："圆的公式到底是先推导证明出来，还是直接写出来后面才补证明？"——答：是从定义一步步等价推导出来的。上面每一步（"在圆上" ⟺ "距离=r" ⟺ "√(x²+y²)=r" ⟺ "x²+y²=r²"）都是等价变形，所以推完就等于证完了，不需要"事后补证明"。这跟"乱写一个公式再去找它对应什么"是两回事。
    圆的变体 · 你追问的 a,b 从哪来

    第 7 章：圆的"搬家"——(x−a)² + (y−b)² = r²

    你问："a、b 莫名其妙出现？是新发现？谁论证的？为什么是 x−a 不是 x+a？"

    上一章圆心在原点。可现实里圆心哪都能放。圆心搬到 (a, b) 会怎样？ 别慌，一步都不用新发明——还是同一个距离公式。

  • 圆的定义没变：圆上点 (x,y) 到圆心 (a,b) 的距离仍然 = r。
  • 套第 5 章的距离公式（两点是 (x,y) 和 (a,b)）：√( (x−a)² + (y−b)² ) = r。
  • 两边平方：(x−a)² + (y−b)² = r²。搬家版出生。
    • 回答你三连问：
    · "a、b 是新发现吗？" 不是。a、b 只是圆心的坐标，是俩代号，不是新数学。用的还是原来那个距离公式。
    · "要不要重新严格论证？" 不用。距离公式对任意两点都成立（第 5 章已立），圆心从 (0,0) 换成 (a,b) 只是代入不同的数，无需新证明。
    · "为什么是 x−a 不是 x+a？" 因为距离公式量的是两点坐标的差：横向差 = 点的 x 减圆心的 a = x−a。差，当然是减法。若写 x+a，量的就不是"点到圆心"的距离了。
    你还问过："为什么不是 新坐标 = 旧坐标 + 平移量？" —— 好问题，这是两个不同视角：你说的是"移动图形"（平移变换），我这里是"量距离"。量距离只关心"点和圆心横竖各差多少"，那个差就是 x−a、y−b。两个视角最后都能得到同一个方程，殊途同归。（"平移变换"那条线，属于后面章节，这里先按下。）
    上面那张交互图，现在拖"圆心 a / b"两个滑块：你会看到圆整体搬家，方程里的 a、b 实时变，而那个"勾股直角三角形"的两条边永远是 x−a 和 y−b，斜边永远是 r。搬到哪，都还是勾股定理。
    收尾 · 你最想要的元层总账

    第 8 章：这一路，哪些是发现、哪些是约定、哪些要证明

    把你反复追问的"数学本质"，在这条具体的线上结个总账
    这一步身份为什么
    勾股定理 a²+b²=c²发现（要证明）平直空间逼出来的真理，靠图形/面积证明
    面积=边长×边长、√ 记号约定怎么量面积、用什么符号，是人规定的
    坐标系 (x,y)约定/发明笛卡尔规定的游戏场地，不需证明
    距离公式 √(Δx²+Δy²)推导（要证明）从坐标约定 + 勾股定理推出来，已证
    圆方程 x²+y²=r²、(x−a)²+(y−b)²=r²推导（等价变形即证明）从圆的定义一步步等价翻译，推完即证完
    把你那句原创洞察精修一下：你说"从图形翻译成代数才要证明，从代数换回图形不需要"。更准确的版本是：——把一个几何定义（圆=距离都等于r）翻译成代数方程时，每一步等价变形本身就是证明；而把一个代数方程画成图形，只是"描点连线"，不产生新命题，所以不需要额外证明。你的方向完全对，只需要把"证明"理解成"每步等价"就严丝合缝了。
    练习 · 检验你真的看穿了
    ① 手算：圆心在 (2, −1)、半径 5 的圆，方程怎么写？点 (5, 3) 在这个圆上吗？
    方程：(x−2)²+(y+1)²=25（注意 y−(−1)=y+1）。代入 (5,3)：(5−2)²+(3+1)²=9+16=25 ✓，正好等于 25，在圆上。你看，"在不在圆上"就是"到圆心距离是不是 r"，还是勾股。
    ② 反问：为什么圆的方程要"两边平方"把根号去掉？不平方（保留 √(x²+y²)=r）不行吗？
    保留根号也完全对，只是带根号的式子难变形、难和别的方程联立。平方后 x²+y²=r² 是纯多项式，好算得多。而且因为 r>0、距离≥0，两边平方是等价的（没引入假根），所以放心平方。这是"为了好算而做的等价整理"，不是新数学。
    ③ 思考：如果空间不是平的（比如在地球表面这种弯曲面上），勾股定理还成立吗？这对"圆的方程"意味着什么？
    不成立。弯曲空间里 a²+b²=c² 会失效（这正是为什么它是"发现"——依赖空间是平的）。既然圆方程 = 勾股定理换衣服，那么弯曲空间里"圆"的方程也会变样。这一步已经踩到大学"微分几何/非欧几何"的门口了——你追问到底，自然就走到了研究生的地界。
